セットアップの順序

  1. 拡張元のWindows PCに、公式spacedesk DRIVERを導入し、有効にします。
  2. MyRoom Viewのサーバーで npm run setup:desktop-viewer を実行します。このサーバーへの導入状態は上の欄で確認できます。
  3. PCのIPアドレスを保存し、「拡張画面を開く」を押して接続します。
  4. Windowsの「設定 → システム → ディスプレイ」で「表示画面を拡張する」を選び、画面の配置を調整します。

MyRoom Viewへの切り替えは上部の「MyRoomへ戻る」で行えます。拡張画面を開いている間は、無操作によるスクリーンセーバーへの切り替えを止めます。

HTML5ビューアーの同時接続は、Windows PC 1台につき1接続です。別のタブ・端末で開いている場合は、先にそちらを閉じてください。Ubuntu VMとWindows PCは同じ家庭内LANに接続してください。
